U-DATA HR - RUN KARNE KA EASY TARIKA

OPTION 1: DOCKER (SABSE EASY)
1. Node.js 22+ aur Docker Desktop install karke open karo.
2. ZIP extract karo.
3. udata-hr-mern folder me START-DOCKER.bat double-click karo. Pehli baar secure .env khud create hoga.
4. Browser me http://localhost:4000 kholo.
5. Terminal me print hua admin password save karo. Email: admin@udata.local
6. Login ke baad Account & settings me password change karo.

Pehli baar internet chahiye. Docker MongoDB aur app dono start karega.
Data MongoDB ke permanent Docker volume me save rahega.

OPTION 2: NODE + MONGODB
1. Node.js 22+ aur MongoDB Community Server install karo.
2. MongoDB service start rakho.
3. START-WINDOWS.bat double-click karo.
4. Terminal par jo admin password print ho, use save karo.
5. http://localhost:4000 kholo.
6. App use karte waqt terminal open rakho.

Source me 11 HR modules hain. Sab React JSX me hain.
Backend: Node.js + Express. Database: MongoDB / Mongoose.
Sample records first start par milenge.
Apna purana actual data import karne ke liye JSON backup chahiye.
Sirf purani HTML file se live records recover nahi hote.
